# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

## In short

- Be respectful and constructive in issues, reviews, commits and discussions.
- Critique code and designs, not people.
- No harassment, discrimination, personal attacks, or publishing anyone's private information.
- Assume good intent, and ask before assuming bad intent.

## Scope

This applies to every project space: the repository, its issues and pull requests, reviews, and any channel where someone represents the project.

## Reporting

Report unacceptable behaviour privately to **hdyousefi@gmail.com**. Reports are reviewed promptly and handled in confidence. The maintainer may remove, edit or reject contributions that don't follow this code, and may restrict anyone who repeatedly or seriously breaks it, following the Contributor Covenant's enforcement guidelines.
