# Adversarial Behaviour

The adversarial analysis that D3 ([failure-modes.md](failure-modes.md)) links to; D3 itself is that file, not this one. It covers what each kind of attacker can try against a permissionless venue, and what stops it. Races and partial failures are in failure-modes.md.

`#n` = finding in [spec-review.md](../reviews/spec-review.md). **Residual** = accepted risk, with its production defence.

| Attacker | Attack | Defence |
|---|---|---|
| Requester | Spam requests to tie up MM attention/capital (#12) | Must hold `qty × limit` summed over its legs (P4), has at most `MAX_LEGS` (8) legs, and every leg is at least `MIN_REQUEST_NOTIONAL` ($1). |
| Requester | Accept a different price than shown | `Accept` must echo quote ids **and** prices; mismatch ⇒ rejected. |
| Requester | Free option: accept only if the market moved its way, else reject or lapse (#10) | **Residual**, inherent to RFQ: bounded by a short `ACCEPT_WINDOW`, and firm quotes stop the MM racing it. Grows with days-long windows. Production: reject/lapse fee to the selected MM; per-requester reject-rate limits. |
| Requester + MM | Shadow RFQ with the same public fields to read the best honest price, then reject (#11) | **Residual**, as above: sealed bids are only as strong as the cost of a shadow RFQ. |
| MM | Spam quotes | Each quote holds full collateral; one active quote per MM per leg. |
| MM | Probe the sealed limit with quote submissions (#2) | `SubmitQuote` doesn't check the limit; selection drops over-limit quotes and `QuoteLost` doesn't say why. |
| MM | Grow the timer index with far-future expiries (#14) | `expires_at` clamped to `response_deadline + ACCEPT_WINDOW`. |
| MM | Undercut by 1 bp after seeing others (#25) | Sealed bids; quote events go only to their owner (`audience`). Egress, Archive and gateways are venue-operated. Production: encrypted or commit-reveal quotes. |
| MM | Win with a quote that expires right after selection | Not eligible unless firm through the whole acceptance window. |
| MM | Win, then cancel in the window to void the RFQ (#1) | Selected quotes are firm (P5): cancelling a `Selected` quote ⇒ `InvalidState`. |
| Either | Self-trade | `mm ≠ requester` rejected. Sybil accounts can't be prevented in a permissionless venue — they only trade with themselves at their own cost. |
| Oracle | Propose a wrong outcome (#8) | Dispute window + bond + arbiter. **Residual:** a wrong proposal costs the oracle nothing. Production: oracle bond per proposal, slashed to the disputer when overturned. |
| Oracle | Stay silent so the contract resolves `Invalid` (#7) | **Residual:** `Invalid` at the hard deadline is the liveness fallback for a trusted (mocked) oracle. Production: oracle bond + auto-escalation to the arbiter at a `proposal_deadline`. |
| Oracle | Propose late so the window outlives the hard deadline (#20) | `ProposeOutcome` needs `now + dispute_window < resolution_deadline`. |
| Oracle / arbiter | Judge its own proposal; trade its own contract; years-long or zero-window listings (#22) | `ListContract` rejects an oracle that is operator, arbiter or treasury, a zero `dispute_window`, and a window that cannot end before `resolution_deadline`. **Residual:** insider trading, `MAX_HORIZON`, `MIN_DISPUTE_WINDOW` are production listing policy. |
| Anyone | Dispute spam (#9) | Bond; one dispute per contract; bond forfeited if the ruling upholds the proposal. **Residual:** a flat $100 bond can freeze any amount of escrow until the arbiter rules. Production: bond scaled to open interest, or an escalation ladder. |
| Anyone | Learn who sent a command, such as the requester behind a public `RequestOpened`, from `EventBatch.origin` | `origin` identifies the sender, so a gateway forwards it only to that actor, like an `Account` audience, and strips it for everyone else. Egress is venue-internal: the same trust boundary as audiences. |
| Anyone | Forge `actor`, or inject `Tick`/`Genesis`/`Resume` (#6) | The gateway authenticates `actor` (out of scope per the brief); `ClientCommand` can't express system commands. Strict nonces: no `u64::MAX` lockout. |
| Anyone | Flood ingress with invalid commands, each one sequenced into the journal (#13) | Malformed or over-64 KiB messages never reach the journal or the engine, but the node warn-logs each drop, unthrottled (a log flood is a residual risk). **Residual:** a well-formed but invalid command is sequenced and journaled. Production stops floods at the gateway (per-actor rate limits, pre-validation) before sequencing; the gateway is out of scope. |
| Anyone local | Act as, or read, any account over the HTTP API: a `POST` naming any `actor`, `GET /v1/accounts/{id}`, or the admin trace (`/v1/trace?view=admin`: every command and every event) | **Residual**, the same as the WebSocket's ([gateway.md §7](gateway.md)): the demo has no authentication, and the port is published on the host's loopback only. Another web site cannot do it through the user's browser: its `Origin` is refused with `403` (a sandboxed iframe's `null` passes, as on the WebSocket). A same-origin `GET` carries no `Origin`, so the `Host` rule is what stops DNS rebinding: `Host` must name `localhost`, `127.0.0.1` or `[::1]` (any port), else `403`. Production: an authenticated session fixes the account of every read and write, and the admin trace is for venue staff only. |
| Anyone local | Tie up the HTTP server: many connections, a head that never ends, large bodies, writes that wait, slow readers, large trace pages | One request per connection, the head within 10 s, a body of at most 64 KiB with `Content-Length`, at most 64 connections (more get `503`) of which at most 48 writes, so 16 are always left to reads, every write goes through the hub's nonce queue and back-pressure, and a trace page holds at most 1,000 entries and 4 MiB of them ([read-api.md §6, §9](read-api.md)). **Residual:** a write waits up to 75 s for its answer (a hung engine, or an actor held behind an unresolved nonce) and holds one of the 48 write slots meanwhile, so 48 such writes refuse every other write for that long (reads still get in); a client that reads its answer slowly holds its slot too (up to 10 s per write of the answer). A single trace entry over 4 MiB (a finalisation batch that settles very many positions) is still served, as a page of its own. Production: per-client limits and rate limits at the gateway, as for ingress floods above. |
| Colluders | 10⁶ tiny positions so one finalisation stalls the single writer (#23) | Each position costs at least `MIN_REQUEST_NOTIONAL` of escrow. **Residual:** production settles in bounded batches or per position (`Claim`). |
| Anyone | Exploit wording found ambiguous mid-life (#24) | **Residual:** resolved `Invalid` at resolution. Production: operator `HaltContract`. |
| Venue-local process | Use the Archive's unauthenticated control session (open to any process sharing the Aeron IPC directory) to stop, truncate or forge log recordings | **Residual:** deployment must give only venue processes the driver directory (the demo client shares it as test tooling). Production: an Archive authenticator; gateways on their own driver. |
| Disk fault | Corrupt one record in the middle of a `FileJournal` | **Residual:** open truncates every record after it, including published ones. It is the fallback journal; the Archive is primary. Production: refuse to start unless the bad record is the unsynced tail. |
| Disk fault | Flip a bit in an Archive record | **Residual:** Archive records carry no per-record integrity check, so the changed field replays silently. Production: Archive record checksums or a CRC in the codec frame, and journaled `state_hash` checkpoints. |
| IPC peer | Open many ingress sessions, each leaving a fragmented message unfinished | **Residual:** the reassembler never evicts a dead session's partial (up to 64 KiB each). Production: drop it when the image goes away; cap partials in flight. |
| Supply chain | Swap a base image or rusteron's Gradle bootstrap | **Residual:** both are pinned by name, not content (the `aeron-all` jar is sha256-checked; crates are locked and audited by cargo-deny). Production: image digests, vendored Gradle artifacts. |
| Anyone | Grow state so the demo's `RFQ_HASH_EVERY_BATCH` slows every batch | **Residual:** demo-only: it hashes the full state after every batch, for the crash-recovery check. Production: off, or a hash at a cadence. |
| Clock fault | Step the wall clock forward while the node runs | **Residual:** the stall `Resume` extends dispute windows only. Trading closes and hard deadlines fire early in real time: an unresolved contract ends `Invalid`, an unruled dispute ends as proposed ([engine.md](engine.md) §6.3, which also covers sustained slow steps). Production: a monotonic clock anchored once to wall time. |
